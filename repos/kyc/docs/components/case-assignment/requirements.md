Functional requirements of the component. Source of truth: this file (changed in the same PR as the code); the
application summary is `repos/kyc/docs/README.md`. Open KYC items are on the "KYC Application" board.

## Case Assignment

- **Purpose:** Who may give a KYC case to a Compliance officer.
- **What it does:** The privilege CASE_ASSIGNMENT - Manage enables Assign Case on the request (205) and case (211) screens.
- **Why:** Case allocation is controlled by role, not by who happens to hold the case.
