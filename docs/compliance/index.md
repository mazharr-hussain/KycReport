# Compliance Overview

This section contains the formal compliance assessment of the KYC system against international regulatory standards.

!!! danger "Overall Score: 39/88 — 44% Compliant"

    The current system meets baseline workflow requirements but has significant gaps in:

    - Structured sanctions/PEP screening evidence capture
    - Ongoing monitoring and periodic review scheduling
    - SAR (Suspicious Activity Report) workflow
    - Password security (plain-text storage)

    The V3 and V4 designs address all identified gaps.

---

## Standards Applied

| Standard | Scope |
|---|---|
| **FATF 40 Recommendations** | Global AML/CFT framework — Customer Due Diligence, Risk-Based Approach |
| **Basel Committee Guidelines** | KYC sound practices for financial institutions |
| **EU 6AMLD** | Beneficial ownership, criminal liability, predicate offences |
| **ISO 31000** | Risk management principles and guidelines |
