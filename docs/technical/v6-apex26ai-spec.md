# V6 — Oracle APEX 26 AI on ATP — Technical Specification

!!! info "Prerequisites"
    - Oracle APEX 26 or later
    - Oracle Autonomous Transaction Processing (ATP) — Oracle Database 23ai
    - Oracle Fusion HCM Cloud (REST API access)
    - OCI IAM Domain configured for SSO
    - OCI Vault for credential storage
    - OCI Object Storage bucket for documents
    - OCI Generative AI Service enabled in tenancy
    - OCI AI Document Understanding enabled in tenancy
